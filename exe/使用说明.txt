万年历（Windows 桌面版）· 使用说明
====================================

这是一个免安装的日历程序：双击「万年历.exe」就能用，
不需要联网、不会上传任何数据、不需要装 Python 或 Node。


一、怎么用
----------

双击 万年历.exe。

  · 程序会打开一个独立的窗口（没有地址栏和标签页，就像一个普通软件）。
  · 首次启动可能慢 1~2 秒，请稍等。
  · 关闭窗口后程序会自动退出。

如果双击后没反应，请在本目录打开命令行执行：

    万年历.exe

看是否有报错信息；也可以用同目录的 使用说明 里的方式排查。


二、里面有什么
--------------

【日历】        月视图 / 年视图 / 列表视图；今日高亮、周末标红、每格显示农历日期
【节日】        429 条，全年 365 天每天至少一条
                含 91 条冷门国际日（国际小狗日、世界穿山甲日、圆周率日…）
【农历与节气】  支持 1900–2100；二十四节气按天文算法计算，含闰月、干支、生肖
【黄历】        每天都有黄道吉日 / 黑道日判定，以及「宜」「忌」
                含建除十二神、二十八宿、月破、四离四绝、杨公忌日等
【历史上的今天】4702 条，每天 12~17 条，含重大历史事件与名人诞辰（全部中文）
                已剔除娱乐、体育类明星；鼠标悬停可看英文原文
【日程】        任意一天可加备忘录、生日、纪念日
                支持 仅此一次 / 每年 / 每月 / 每周 / 农历每年 循环


三、你的数据保存在哪
--------------------

数据保存在本程序专用的浏览器配置目录里（在系统临时目录下的
calendar-app-profile 文件夹）。它跟着这台电脑走，不会上传。

  ! 把 exe 拷给别人时，你自己的日程不会一起过去。

想把日程带走或给别人：

  1. 打开程序 → 右上角「数据」→「导出 JSON 文件」
  2. 把导出的 json 文件拷贝过去
  3. 对方打开程序 →「数据」→「导入 JSON」

  * 如果系统清理了临时目录，数据可能丢失。重要内容请定期用上面的方式导出备份。


四、快捷键
----------

  ← →    上一月 / 下一月
  T      回到今天
  N      新建日程
  /      搜索
  Esc    关闭弹窗

点日历上任意一格，可以看当天【节日 + 黄历宜忌 + 历史上的今天】，也能在当天加日程。


五、常见问题
------------

Q: 提示「没有找到可用的浏览器」？
A: 本程序需要系统里有 Edge 或 Chrome（用于显示界面，Windows 一般自带 Edge）。
   若确实没有，程序会退回用系统默认浏览器打开，此时需要保持本程序运行。

Q: 杀毒软件提示风险？
A: exe 是本目录下的 C# 源码（CalendarApp.cs）编译而成，没有加壳、不联网。
   如不放心，可以直接用同版本的 calendar.html（纯网页版，双击即用）。

Q: 想要更小的体积？
A: 网页版 calendar.html 只有 995 KB，功能完全相同，双击即可打开。


六、数据来源与说明
------------------

  · 农历 / 节气：天文算法计算（Meeus 太阳视黄经 + ΔT 修正），已与公开历书逐日校验。
  · 黄历：按公开通书规则推算，不同流派在个别宜忌条目上会有差异，仅供参考。
  · 历史上的今天：整理自 Wikipedia 各日期条目；中文为机器翻译，
    个别专有名词可能不够统一，鼠标悬停可看英文原文核对。
