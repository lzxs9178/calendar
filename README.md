# 万年历 · 节日与日程

> 一个完全离线的中文日历程序：**每一天都有节日**、**黄历宜忌**、**历史上的今天**，
> 还能添加自己的备忘录、生日与纪念日（支持农历、每年循环）。
>
> 浏览器端**零依赖**，不用装任何东西；也可以打包成 Windows 桌面程序。

## ✨ 功能

| 模块 | 说明 |
| --- | --- |
| **日历** | 月视图 / 年视图 / 列表视图；今日高亮、周末标红；每格显示公历日 + 农历 |
| **节日** | **429 条，全年 365 天每天至少一条**；含 91 条冷门国际日（国际小狗日、世界穿山甲日、圆周率日、世界水獭日…） |
| **农历与节气** | 1900–2100；二十四节气由**天文算法**计算（Meeus 太阳视黄经 + ΔT 修正）；含闰月、干支、生肖 |
| **黄历** | 每天都有**黄道吉日 / 黑道日**判定与**宜·忌**；含建除十二神、二十八宿、月破、岁破、四离四绝、杨公忌日等 |
| **历史上的今天** | **4702 条**，每天 12~17 条，含重大历史事件与名人诞辰；**已剔除娱乐/体育明星**；全部中文，悬停可看英文原文 |
| **日程** | 任意一天可加备忘录 / 生日 / 纪念日 / 待办；支持 `仅此一次`、`每年`、`每月`、`每周`、`农历每年` |
| **数据** | localStorage 本地保存，不联网、不上传；支持导出 / 导入 JSON、导出 CSV |

细节：

- **生日同步到每年**，自动标注"第 N 年"；2 月 29 日生日平年顺延 3/1
- **农历生日**按农历月日每年同步（公历日期每年变化）；该月无三十时自动落到廿九
- 侧栏「即将到来」按天数排序：今天 / 明天 / N 天后
- 键盘：`←` `→` 翻月、`T` 今天、`N` 新建、`/` 搜索、`Esc` 关闭
- 深色模式、周序号、周一起始、紧凑模式

## 🚀 快速开始

### 方式一：网页版（最简单）

下载 `calendar.html`，**双击**用浏览器打开即可。单文件自包含，可以单独拷给别人。

### 方式二：Windows 桌面版

下载 `exe/万年历.exe`，双击运行。免安装、不联网；会用 Edge/Chrome 的无边框窗口显示，关窗自动退出。

### 方式三：本地服务器（推荐长期使用）

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git
cd <仓库名>
python -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

> 为什么推荐这种方式：Chrome / Edge 直接双击 `file://` 打开时**不允许网页保存数据**，
> 通过 http 访问才能稳定保存（Firefox 双击则可以）。

### 方式四：自己构建

```bash
node build-standalone.cjs   # 生成自包含单文件 calendar.html 与 docs/ 部署版
npm run build:exe           # 生成 Windows exe（需 Windows 自带 .NET 编译器）
```

## 📁 项目结构

```
.
├─ calendar.html              # 自包含单文件（双击即用，构建产物）
├─ index.html                 # 开发入口（引用外部 css/js）
├─ css/style.css              # 全部样式（浅色/深色、响应式、打印）
├─ js/
│  ├─ lunar.js                # 农历 / 二十四节气 / 干支生肖（天文算法，无依赖）
│  ├─ festivals.js            # 节日库（固定公历 + 农历 + 浮动规则 + 节气，全年无空缺）
│  ├─ almanac.js              # 黄历引擎（建除十二神 / 黄黑道 / 二十八宿 / 神煞 / 宜忌）
│  ├─ history.js              # 历史上的今天（4702 条中文，脚本生成）
│  ├─ events.js               # 用户日程引擎（重复规则 / 下次发生 / 序列化）
│  └─ app.js                  # 界面逻辑（月/年/列表视图、编辑弹窗、存储）
├─ docs/                      # GitHub Pages 可直接部署（index.html + js + preview.png）
├─ exe/                       # Windows 桌面版：C# 源码 + 构建脚本
├─ tools/                     # 自检与构建脚本（Node 18+，程序本体不需要）
└─ LICENSE
```

`lunar.js` / `festivals.js` / `almanac.js` / `history.js` / `events.js` 同时兼容浏览器与 Node：

```js
const Lunar = require('./js/lunar.js');
Lunar.fromSolar(2025, 1, 29);            // 农历正月初一

const Almanac = require('./js/almanac.js');
Almanac.of({ year: 2026, month: 10, day: 11 });
// 丙午年 戊戌月 戊午日、成日、天刑、角宿、黑道日

const HistoryDB = require('./js/history.js');
HistoryDB.of(10, 11).length;             // 当天 12 条历史事件与诞辰
```

## 🔍 黄历与历史数据的说明

这两块是**传统术数规则 / 二次整理的中文数据**，需要说清楚边界：

### 黄历（`js/almanac.js`）

- 不是天文计算，而是按**公开通书规则**实现：建除十二神、黄黑白道十二神、二十八宿、
  四离四绝、杨公忌日、十恶大败日、受死日等。
- **不同流派在个别宜忌条目上会有差异**，本程序给出的是推算结果，仅供参考。
- 日柱、月柱已与公开通胜逐日校准（例：`2026-10-11 = 丙午年 戊戌月 戊午日`）。

### 历史上的今天（`js/history.js`）

- 数据整理自 **Wikipedia 各日期条目**（经 [history.muffinlabs.com](https://history.muffinlabs.com/)
  提供的结构化接口），由 `tools/build-history.cjs` 抓取、筛选、翻译后生成。
- 已剔除演员 / 歌手 / 球员等娱乐体育类人物；自动抽取的诞辰只保留 1940 年前出生者。
- 另有 310 条**人工精选**条目（`tools/curated-history.cjs`），特别补充中国与东方历史。
- 中文由**多智能体并行翻译**完成（双遍交叉校验），个别专有名词可能不够统一；
  界面里保留了英文原文，悬停即可核对。
- ⚠️ Wikipedia 内容为 **CC BY-SA** 许可，再分发该数据时请保留来源标注。

### 农历与节气（`js/lunar.js`）—— 这部分是硬核实算

- **节气**：不用常见的"分种近似表"（那种表 200 年跨度会有 ±1 天误差），而是用
  Meeus 太阳视黄经公式迭代求解，并做 **ΔT（TT−UT）修正**，按北京时间取日期。
- **农历**：以经典压缩表为基础，并用**天文朔日**（Meeus 朔望月公式）+「无中气置闰」规则
  对 1900–2100 共 2486 个月逐位校验，修正了 2060、2097 两处月长错误
  （这两处在多个公开 JS 库里同样存在）。
- 与 `solarlunar@3.1.0` 在 1900–2059 全区间**逐日完全一致**。

## 🧪 开发与自检

```bash
npm install          # 只装自检用的 jsdom / solarlunar（程序本体零依赖）
npm run verify       # 12 个套件、约 250 项检查
```

| 套件 | 检查内容 |
| --- | --- |
| `verify-files` | 产物完整性（编码、结构、内联脚本可解析） |
| `verify-almanac` | 黄历：干支 / 建除 / 黄黑道 / 二十八宿 / 宜忌完整性 |
| `verify-history` | 历史数据：366 天覆盖、字段合法、已剔除明星、全部中文 |
| `verify-boot` | 三种存储环境（可用 / 抛错 / 无）下的启动自检 |
| `verify-buttons` | **真点击 10 次**，验证按钮是否真的可用 |
| `verify-boot-fallback` | 启动失败时不会白屏（兜底提示） |
| `verify-boot-regression` | "卡在开头"崩溃场景的回归测试 |
| `verify-diagnose` | 诊断页本身是否正确 |
| `verify-standalone` | 单文件版交互 |
| `verify` | 农历节气对天文、日程引擎、节日库、jsdom 界面 |
| `verify-exe` | 从 exe 里取页面跑真实界面 |
| `verify-exe-window` | exe 的浏览器选择逻辑 |

## 🤝 参与贡献

欢迎提 Issue / PR。几个适合上手的方向：

- **补充节日**：编辑 `js/festivals.js`，按三种规则加一行即可
  ```js
  f(3, 23, '国际小狗日', '趣味', ['冷门', '宠物']);   // 固定公历
  lu(8, 15, '中秋节', '公休', ['法定假期']);          // 农历
  fl(5, 0, 2, '母亲节', '家庭', ['西方节日']);        // 5 月第 2 个周日
  ```
- **补充历史事件**：编辑 `tools/curated-history.cjs`
- **法定假期调休**：`js/festivals.js` 里已有 `SPECIAL` 年份特例结构
- **更多语言**：`js/app.js` 里的文案目前是中文硬编码，可抽成 i18n
